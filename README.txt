김민준 ♥ 이서연 웨딩 청첩장
=============================

실행 방법
1. 압축을 풉니다.
2. index.html 파일을 크롬 또는 엣지 브라우저에서 엽니다.
3. 인터넷 연결이 있으면 웹폰트가 적용됩니다. 사진은 assets 폴더의 로컬 이미지이므로 외부 이미지 주소가 끊겨도 표시됩니다.

폴더 구성
- index.html : 웹페이지 구조
- css/style.css : 디자인 및 반응형 스타일
- js/main.js : 사진 확대, 계좌번호 복사 및 팝업 기능
- assets/ : 청첩장 시안에서 추출한 실제 사진 파일

수정할 내용
- 예식 날짜, 시간, 장소, 주소
- 은행명과 계좌번호
- 지도 링크의 주소
index.html에서 해당 문구를 검색해 수정하면 됩니다.

참고
현재 날짜·장소·계좌번호는 시안의 예시 정보입니다. 실제 배포 전 반드시 정확한 정보로 변경하세요.
지도 링크는 구글 지도 검색 링크이며, 예시 주소를 기준으로 연결됩니다.
